# Oversikt

## Hva jeg har gjort
I denne prosjekted så har jeg jobbet med å lære hvordan man kan bruke md dokumenter til å skrive en readme oversikt.

## Mine refleksjoner
    · Hva har du lært om Git og GitHub?
    Jeg har lært meg hvordan man kan navigere og bruke funksjoner på GitHub.
	· Hva synes du om å bruke versjonskontroll?
    Jeg synes at versjonskontroll er veldig fint og blir enda bedre sennere
    når jeg kommer til å programmere enda mer en det jeg gjør nå,
    som gjør det lettere å teste code
	· Hva har du lært om Markdown?
    Det jeg har lært om markdown er hvordan man kan sette in linker, bilder sette in code
    og hvordan man kan endre på hvordan skriften ser ut.
	· Hvordan kan Markdown brukes til dokumentasjon?
    Ved å skrive hva du har gjort på forskellige datoer, og skrive hva som har blitt endret.
    · Hva var mest utfordrende?
    Å først lære hva de forskjellige tingene på github er/gjør.

## Bli kjent med JavaScript
    · Hva har du prøvd ut?
    Det jeg har prøvd ut er å få knapper till å virke på nettsiden men også få ting til å skje i consolen.
    · Hva har du lært?
    Det jeg har lært er hvordan man kan lage knapper som gjør en endring i console eller på nettsiden.
    · Eventuelle utfordringer du møtte
    Utfordringer jeg møtte på var på starten å skrive koden riktig sånn at programmet skjønte hva du prøvde på.
